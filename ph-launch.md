## Description (~485/500)

Ask an AI a hard question and it forms a committee: fifty sub-agents, fifty essays, nobody decides. That's not orchestration, that's a support group. Tony Protocol is a one-file Claude Code skill that runs the crew like a family business — the other kind. Everyone gets one job. No receipt, no table. Dead branches take a drive to the Pine Barrens. Silvio gets one shot at the answer. Tony makes the call before Christopher finishes his screenplay. Small decisions get ruled in the hallway.

## Maker first comment

Maker here. I run a lot of multi-agent work on Fable and Opus, and the honest truth is orchestration is a mess the moment you need an actual decision. You ask a hard question, the model hires a committee, and forty minutes later you've got fifty essays and a summary saying "both approaches have merit." Nobody gets fired. Everyone's perspective is valid. It's minestrone.

Tony Protocol introduces a more effective management structure: organised crime.

Keep the crew small. Give everyone one job. Demand receipts. Junior attacks the plan before anyone gets hired. Silvio gets one shot at killing the answer before you see it. Dead branches take a drive to the Pine Barrens. Tony makes the call.

It started as a joke and then it kept being right. It's ruled on three real decisions so far, and every release is named after the lesson a real run taught it — v0.4.1 is "The Wedding": everybody attended, it cost a fortune, and the same two people still made the decision anyway. That's now a punishable offence.

The family doesn't punish bad news. It punishes bad paperwork.

What would Tony do?

## Shoutout blurbs

**Claude Code:** Tony Protocol is a Claude Code skill — the whole thing is one markdown file that Claude Code turns into a working orchestrator. Skills as a distribution format is quietly brilliant: no framework, no install script, no dependencies. Copy a file, say "Tony, run the family on this," and you've got a crew.

**Claude (Anthropic):** The family runs on the model tiers: Opus does the hard thinking in two seats (the guy who attacks the plan, the guy who attacks the answer), Sonnet runs the capos, Haiku does the legwork. The protocol's economics only work because you can match the model to the seat — you don't pay a boss's rate for a soldier's job.
